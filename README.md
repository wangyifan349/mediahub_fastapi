# MediaHub 1.5
MediaHub 是一个基于 FastAPI + Bootstrap 5 + SQLite + SQLAlchemy + Jinja2 的轻量图片/视频分享平台。1.5 版在保留宽屏界面、实时 LCS 搜索和作品管理功能的基础上，进一步简化后端代码结构。数据库连接、数据模型、密码哈希和 FastAPI 路由集中在 `main.py`，减少小项目中过度拆文件和过度封装，方便直接阅读和修改。

## 功能介绍
- 用户系统：支持注册、登录、退出，密码使用 PBKDF2-SHA256 哈希保存；密码输入不设置最短或最长长度限制。
- 媒体上传：登录用户可以上传图片和视频，图片支持 JPG、JPEG、PNG、GIF、WebP，视频支持 MP4、WebM、MOV、M4V，默认单文件最大 1 GiB。
- 作品展示：公开作品会显示在首页、搜索结果和用户个人主页；作者可以随时将作品设为“不再展示”，也可以重新公开。
- 隐藏保护：作品停止展示后，不只是在页面上隐藏，普通用户直接访问作品详情或媒体文件接口也无法查看；作者本人和管理员仍可访问和管理。
- 在线查看：图片可以直接预览，视频可以在浏览器中在线播放。
- 下载功能：首页作品卡、播放详情页和创作中心都有明确下载入口，下载原文件并记录下载次数。
- 实时搜索：顶部搜索框输入时自动刷新联想结果，可搜索作品和用户；作品标题/作者名与用户名使用最长公共子序列（LCS）计算匹配长度，并按 LCS 长度降序排列。按回车进入完整搜索结果后仍保持相同排序逻辑。
- 评论功能：登录用户可以在作品详情页发表评论；评论者可以删除自己的评论，作品作者和管理员也可以删除作品下的评论。
- 作品管理：用户可以在“我的作品”页面查看自己上传的内容、展示状态、浏览次数、下载次数，并使用小型按钮快速下载、隐藏/显示或永久删除作品。
- 用户主页：采用横幅、头像、作品/浏览/下载统计和宽屏投稿网格，更接近视频社区个人空间。
- 创作中心：侧栏式作品管理界面，集中显示作品总数、公开作品、总浏览、总下载，并可下载、隐藏、重新展示或删除作品。
- 播放详情：大尺寸播放器/图片查看区，右侧显示其他公开作品推荐，评论和作者信息集中在主内容区。
- 管理员用户管理：管理员可以查看用户账号、角色、作品数、评论数和注册时间，并可调整其他用户的管理员角色。
- 权限管理：普通用户只能管理自己的作品；管理员可以管理平台上的作品和评论。
- 数据统计：记录作品浏览次数和下载次数。
- 基础安全：包含 CSRF 防护、随机文件名、登录权限检查、作品访问权限检查和上传类型限制。
- 数据库兼容：如果使用旧版 `media.db`，程序启动时会自动为旧 `media` 表补充 `is_visible` 字段。
- 界面主题：主要自定义界面颜色按照 RGB 的 B（蓝色通道）= 0 设计；顶部导航进一步压薄，登录/注册采用居中卡片并统一字体、间距和输入框尺寸。

## 项目结构
```text
mediahub_fastapi/
├─ main.py              FastAPI 主程序；数据库、模型、密码、路由都集中在这里
├─ requirements.txt     Python 依赖
├─ templates/           Jinja2 页面模板
├─ static/css/          Bootstrap 补充样式
├─ uploads/images/      图片文件
├─ uploads/videos/      视频文件
└─ media.db             首次运行后自动创建
```

代码原则：这个项目体量较小，不额外拆 `service`、`manager`、`repository` 等层；普通查询和业务判断尽量直接写在对应 FastAPI 路由里。只保留数据库 Session、密码哈希、CSRF、当前用户、媒体路径和 LCS 等真正重复使用的基础函数。

## 安装与启动
要求已经安装 Python。第一次使用时，在项目目录执行一次依赖安装：
```powershell
pip install -r requirements.txt
```
以后启动不需要再输入 uvicorn 命令，直接双击项目根目录的 `启动.bat` 即可。程序已经在 `main.py` 中固定监听 `0.0.0.0:8000`，本机访问地址为 `http://127.0.0.1:8000`，同一局域网中的其他设备可使用 `http://本机局域网IP:8000` 访问。如果需要修改端口，直接修改 `main.py` 最下面 `uvicorn.run()` 中的 `port=8000` 即可。`reload=False` 是有意设置的，双击运行时更稳定，也不会因为代码文件变化自动重启进程。
## 管理员账号
管理员为可选功能。第一次启动前可以在 PowerShell 中设置：
```powershell
$env:MEDIAHUB_ADMIN_USER="admin"
$env:MEDIAHUB_ADMIN_PASSWORD="ChangeMe123!"
$env:MEDIAHUB_SECRET_KEY="请替换为足够长的随机字符串"
python main.py
```
程序只会在数据库不存在同名用户时自动创建管理员；如果数据库中已经有该用户名，不会自动把普通用户提升为管理员。

## 数据和文件
SQLite 数据库默认保存在项目根目录的 `media.db`。上传的图片保存在 `uploads/images/`，视频保存在 `uploads/videos/`。媒体页面不会直接公开真实磁盘路径，而是通过受权限控制的媒体接口读取文件，因此隐藏作品仍然会经过后端权限检查。

## 作品展示与隐藏
作者可以在“我的作品”或作品详情页切换展示状态。公开状态下，作品可以出现在首页、搜索和作者主页，并允许普通访问；隐藏状态下，作品从公开页面撤下，普通用户访问详情或媒体内容会得到 404，作者本人和管理员仍然能够查看、重新公开或删除。

## 评论规则
评论需要登录后发表。普通用户可以删除自己的评论；作品作者可以管理自己作品下的评论；管理员可以删除任意评论。隐藏作品不会向无权限用户公开评论区。

## 生产环境建议
当前版本适合作为完整基础版和二次开发起点。如果需要正式公开部署，建议增加 HTTPS、Nginx/Caddy、严格的文件魔数检测、病毒扫描、FFmpeg 视频转码和封面生成、PostgreSQL、Redis、S3/MinIO 对象存储、上传配额、限速、举报审核、分页、点赞收藏关注以及更完整的管理员后台。
